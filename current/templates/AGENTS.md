# Workbook releases

Publish the full SRAM analysis workbook in this directory as
'SRAM Extra BLK Failure  Analysis_v13.1.xlsm'. Keep the two spaces between
'Failure' and 'Analysis'. The next versions are v13.2, v13.3, and so on,
incrementing the first digit after the decimal. Update default workbook paths
in current/tools when renaming a release.

The Address Data Auto output workbook has its own release numbering.
