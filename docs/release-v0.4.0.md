# v0.4.0 — 大型 ASC 分段匯入

針對約 265,646 KB 的 ASC 在整檔讀取時可能發生「字串空間不足」問題，改為：

- 每次讀取 64 KB，不建立整份 ASC 字串或整檔正規表示式比對集合。
- 保留跨段的 TNO 與方括號地址，處理分段邊界的 UTF-8 字元及換行。
- 去重只儲存地址與列號；以暫存工作表累積結果，每批最多 1,000 列寫入正式輸出。
- Log 累積到 500 筆時分批寫入，避免整份 Log 留在記憶體。
- 狀態列顯示讀取進度、唯一地址數與略過筆數；錯誤 Log 記錄目前處理階段。

限制：單檔小於 2 GB，最多 1,048,575 筆唯一地址；未閉合方括號超過 16,384 字元會記錄並略過。唯一地址索引與 Excel 儲存格仍需記憶體。

驗證：20 種地址案例、1/7/65,536 字元分段邊界、Log 來源行號、EOF 與過長記錄防護均通過。272,021,735 bytes 合成檔（主要為填充內容、少量地址案例）已通過分段解析，保留的未解析緩衝最高 128 字元。這不是大量唯一地址的寫入效能測試，也不是實際 ASC 驗證。

VBA 已內嵌且經獨立抽取比對。建置環境沒有桌面版 Excel，二進位解碼及 Excel 匯入/Log 寫入仍待實機驗證。
