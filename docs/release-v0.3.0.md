# v0.3.0 — Import Log

下載新的 `ASC_Fail_Address.xlsm`，VBA 已內嵌。

- 新增 Import Log 分頁，記錄時間、Run ID、Level、Stage、ASC 路徑、TNO、來源行號、錯誤代碼、原因及原始內容。
- 每次執行追加歷史紀錄；INFO 記錄開始、取消與完成摘要，WARN 記錄略過地址，ERROR 記錄匯入失敗。
- 範圍錯誤顯示實際值及允許範圍；非整數顯示欄位位置與內容。
- 跨行地址使用起始行號；缺少結尾方括號也會進入檢查並寫入原因。
- 若 log 無法保存，對話框會另行顯示原因。關閉 Excel 前請儲存活頁簿，以保留 log。

驗證：20 種地址案例、多 TNO 去重及 log 原因、TNO、來源行號、錯誤代碼通過；內嵌 VBA 經獨立抽取確認一致。尚未取得真實 ASC，且建置環境沒有桌面版 Excel，尚未完成 Excel 實機的匯入及工作表 log 寫入驗證。
