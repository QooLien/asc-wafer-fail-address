# v0.6.0 — 無 Log 最佳化與運行時間

請下載本次附件 **ASC_Fail_Address_Fast.xlsm**。VBA 已內嵌，沿用 Config 的選檔匯入按鈕。

- 完全停用逐筆 Log，避免紀錄膨脹及 Import Log 列數已滿錯誤。
- 每次以 256 KB 分段讀取；以地址字典與 Byte 位元旗標合併資料，保留原本六欄地址及各 TNO 的空白/1 規則。
- 移除解析期間的逐筆 Excel 寫入與暫存工作表，改為依欄數調整的批次輸出。
- 執行期間暫停畫面更新、事件及自動計算，結束時恢復。
- 完成視窗新增 `Run time (hh:mm:ss)` 與總秒數，從選定 ASC 後開始計時。
- 保留 Calibri 置中、26 pt 固定列高及原生選檔按鈕。

已通過：20 種地址案例、900 個 TNO、容量擴增、去重與批次輸出核對、約 259 MB 合成檔解析、內嵌 VBA 一致性、排版與按鈕連結，以及 Microsoft Open XML SDK Office2016 格式驗證（0 錯誤）。
